# jesusesrey_system

Sitio web de la **Iglesia Jesús es Rey**, San Martín de los Andes. Astro estático, sin API ni servicios externos.

## Secciones
Inicio · Historia · Nosotros · Horarios · Ministerios · Prédicas · Eventos · Galería · Contacto (con pedido de oración por WhatsApp)

## Editar contenido
Todo el contenido (horarios, ministerios, creencias, eventos, contacto) está en [`src/data/site.ts`](src/data/site.ts). Los textos actuales son marcadores de posición.

## Comandos
```
npm install
npm run dev      # http://localhost:4321
npm run build    # genera dist/
npm run preview
```

Requiere Node >= 22.22.
